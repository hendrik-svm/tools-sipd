# SIPD Tools - Userscript
Script ini untuk membatu anda mencari realisasi pertanggal di SIPD Penatausahaan


## INSTALASI
### Langkah 1. Instal Tampermonkey
pasang ekstensi Tampermonkey pada browser yang digunakan.
https://www.tampermonkey.net/
setelah ekstensi tampermonkey dipastikan sudah terinstal di browser, lanjut langkah 2

### Langkah 2. Aktifkan Developer Mode dan Allow User Scripts
Sebelum menginstal userscript ini, aktifkan terlebih dahulu:
- **Developer Mode** pada browser
- **Allow User Scripts**
Panduan pengaturan dapat dilihat pada gambar berikut:
https://raw.githubusercontent.com/hendrik-svm/mod-ekinerja/refs/heads/main/Developer%20Mode%20dan%20Allow%20User%20Scriptt.png

### Langkah 3: Memasang (Install) UserScript SIPD Tools
Setelah persiapan di atas selesai, Anda tinggal memasang skripnya dengan satu kali klik:
1. Klik tautan langsung pemasangan skrip di bawah ini:
   👉 **[KLIK DI SINI UNTUK PASANG SKRIP SIPD TOOLS](https://raw.githubusercontent.com/hendrik-svm/tools-sipd/main/sipd.user.js)**
2. Browser Anda akan otomatis membuka halaman konfirmasi pemasangan dari Tampermonkey.
3. Anda akan melihat tombol **Install** (Pasang) di bagian kiri atas. Silakan klik tombol **Install** tersebut.
4. Selesai! Sekarang silakan buka atau segarkan (*refresh*) halaman SIPD Anda. Skrip pembantu akan langsung aktif dan siap digunakan secara otomatis.
